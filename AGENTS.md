# Repository Guidelines

## Structure & Development

Keep this buildless static site small: `index.html` is the setup page and `callback.html` is the fixed callback entry point; preview with `python3 -m http.server 8000` and use two-space indentation in HTML, CSS, and JavaScript.

## Validation & Contributions

Check both pages locally, keep callback parameters out of persistent storage, and make small, focused changes; always obtain user approval before creating a commit.
